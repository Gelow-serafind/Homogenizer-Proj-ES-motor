# 详细测试用例 — ES 电机驱动板

> **定位**：本文档是测试的唯一依据。完成的定义 = 所有用例执行通过即软件达标。
> **编号规则**：`TC-<域>-<序号>`，域与需求一致（DISP/IN/SM/MOT/TEMP/TIMER/ICON/STOR/SYS）。
> **场景类别**：正常流 / 边界值 / 异常流。
> **需求跟踪**：每条用例绑定 `REQ-XXX`；文末附双向需求跟踪矩阵（验收方式）。
> **通用测试环境**：Keil 编译固件（ARMCLANG V6.19+）烧录 HK32F0301MF4P7C 目标板；5V 供电；屏已点亮且 VLCD 已调；调试串口 115200 8N1。
> **测试工具**：秒表、转速参考计（频闪仪/光电转速表）、标准温度计或精密电阻箱、镊子/杜邦线（按键与拔插模拟）。

**用例总数：57 条**（正常流 38 / 边界值 11 / 异常流 8）。

## 1. 显示域用例

### TC-DISP-01 上电界面布局
- **对应需求**：REQ-DISP-01, REQ-ICON-05
- **场景类别**：正常流
- **前置条件**：固件已烧录，屏已点亮；Flash 中有已保存参数（如 1500 RPM / 1:00:00）
- **操作步骤**：1) 上电；2) 观察屏面。
- **预期结果**：可见 4 组数据区（Set Speed、Set Time、Instant Speed、Instant Temp、Remaining Time 标签及数字区）、右上角图标区；隔断线 `----` 常显；Instant Speed 显示 0、Remaining Time 显示 00:00:00。

### TC-DISP-02 转速 4 位 + Rpm 格式
- **对应需求**：REQ-DISP-02
- **场景类别**：正常流
- **前置条件**：待机
- **操作步骤**：1) 进入设置设置目标转速为 2000；2) 再设置为 100。
- **预期结果**：2000 → 显示 `2000` + `Rpm` 单位段；100 → 高两位空位熄灭、显示 ` 100` + `Rpm`；`Rpm` 段常显。

### TC-DISP-03 时间 H-M-S 格式
- **对应需求**：REQ-DISP-03
- **场景类别**：正常流
- **前置条件**：待机
- **操作步骤**：1) 进入设置，将时间设为 1:23:45；2) 确认后观察 Set Time；3) 启动后观察 Remaining Time。
- **预期结果**：Set Time 显示 H=0001、m=23、s=45，H/m/s 单位段点亮；Remaining Time 运行后同格式显示。

### TC-DISP-04 温度 888.8℃ 格式
- **对应需求**：REQ-DISP-04
- **场景类别**：正常流
- **前置条件**：PT1000 已插入，环境温度 20~30℃
- **操作步骤**：上电，观察 Instant Temp。
- **预期结果**：显示如 ` 25.6℃` 格式（3 位整数 + 小数点 + 1 位小数 + ℃ 段），与标准温度计一致（±1℃）。

### TC-DISP-05 编辑字段闪烁与停闪
- **对应需求**：REQ-DISP-05
- **场景类别**：正常流
- **前置条件**：待机
- **操作步骤**：1) 单击旋钮进入设置；2) 观察 SPEED 字段 10s；3) 不做任何操作等待 5s。
- **预期结果**：SPEED 字段按约 0.5s 周期亮灭交替闪烁，其他字段不闪；5s 后闪烁停止、退出设置；再单击进入并旋转 1 格，闪烁重新计时 5s 后才停闪。

### TC-DISP-06 探头拔出温度整块隐藏 / 插回恢复
- **对应需求**：REQ-DISP-06
- **场景类别**：异常流
- **前置条件**：待机，PT1000 已插入，温度正常显示
- **操作步骤**：1) 拔出 PT1000 探头；2) 等待 2s 观察；3) 重新插入；4) 等待 2s 观察。
- **预期结果**：拔出后 Instant Temp 数字、标签、℃ 段整块熄灭（≤1s 内）；插回后恢复显示当前温度读数。

### TC-DISP-07 图标渲染联动（抽样）
- **对应需求**：REQ-DISP-07
- **场景类别**：正常流
- **前置条件**：待机
- **操作步骤**：依次执行 TC-ICON-01 ~ TC-ICON-06 的抽查步骤。
- **预期结果**：图标区渲染与各图标用例预期一致（联动引用，不重复定义步骤）。

## 2. 输入域用例

### TC-IN-01 顺时针旋转 +10 RPM
- **对应需求**：REQ-IN-01, REQ-IN-05
- **场景类别**：正常流
- **前置条件**：设置中编辑 SPEED，当前值 100
- **操作步骤**：顺时针旋转旋钮 1 格。
- **预期结果**：Set Speed 显示 110；再旋 1 格显示 120（每格 +10）。

### TC-IN-02 逆时针旋转 −10 RPM
- **对应需求**：REQ-IN-01, REQ-IN-05
- **场景类别**：正常流
- **前置条件**：设置中编辑 SPEED，当前值 120
- **操作步骤**：逆时针旋转 1 格。
- **预期结果**：显示 110；再旋 1 格显示 100。

### TC-IN-03 快速连续旋转不丢步
- **对应需求**：REQ-IN-01
- **场景类别**：边界值
- **前置条件**：设置中编辑 SPEED，当前值 100
- **操作步骤**：以约 3~5 格/秒快速顺时针旋转 20 格后停止。
- **预期结果**：显示 300（+200），无丢步、无方向误判、无跳变。

### TC-IN-04 单击字段循环
- **对应需求**：REQ-IN-02
- **场景类别**：正常流
- **前置条件**：待机
- **操作步骤**：1) 单击旋钮；2) 观察闪烁字段；3) 再连续单击 4 次，记录每次闪烁位置。
- **预期结果**：依次为 SPEED → TIME_H → TIME_M → TIME_S → SPEED（回到起点，完成一个循环）。

### TC-IN-05 转速下限钳位
- **对应需求**：REQ-IN-05, REQ-IN-07
- **场景类别**：边界值
- **前置条件**：设置中编辑 SPEED，当前值 100（下限）
- **操作步骤**：逆时针旋转 5 格。
- **预期结果**：数值保持 100 不变（钳位，不回绕到 2000）。

### TC-IN-06 转速上限钳位
- **对应需求**：REQ-IN-05, REQ-IN-07
- **场景类别**：边界值
- **前置条件**：设置中编辑 SPEED，当前值 2000（上限）
- **操作步骤**：顺时针旋转 5 格。
- **预期结果**：数值保持 2000 不变（钳位，不回绕到 100）。

### TC-IN-07 时间边界 9999:59:59 与 M/S 循环
- **对应需求**：REQ-IN-06, REQ-IN-07
- **场景类别**：边界值
- **前置条件**：设置中编辑时间
- **操作步骤**：1) H 调到 9999 再顺时针 1 格；2) M 调到 59 再顺时针 1 格；3) M=0 再逆时针 1 格；4) S 同 M 操作。
- **预期结果**：H=9999 保持（钳位）；M/S 59→0、0→59（循环）；最终可组合出 9999:59:59 显示。

### TC-IN-08 START 键消抖与长按
- **对应需求**：REQ-IN-03
- **场景类别**：边界值
- **前置条件**：待机
- **操作步骤**：1) 快速连按 START 10 次；2) 长按 START 3s 不放后松开。
- **预期结果**：每次按下沿仅触发 1 次启动/恢复逻辑（状态机切换次数与按压次数一致）；长按只触发 1 次，不重复触发。

### TC-IN-09 STOP 键消抖
- **对应需求**：REQ-IN-04
- **场景类别**：边界值
- **前置条件**：运行中
- **操作步骤**：快速连按 STOP 5 次。
- **预期结果**：状态在暂停/恢复间按按压次数精确切换，无重复事件导致的跳变或漏触发。

### TC-IN-10 非编辑态旋转无效
- **对应需求**：REQ-IN-07
- **场景类别**：异常流
- **前置条件**：待机（未进设置），记录当前 Set Speed/Set Time
- **操作步骤**：顺时针/逆时针各旋转 10 格。
- **预期结果**：所有显示与参数不变；随后按 START 启动，按原目标运行。

## 3. 状态机域用例

### TC-SM-01 上电待机不自动启动
- **对应需求**：REQ-SM-01, REQ-SM-08
- **场景类别**：正常流
- **前置条件**：Flash 已保存参数（如 1500 RPM / 1:00:00），PT1000 已插入
- **操作步骤**：上电，观察 10s。
- **预期结果**：电机不转；Set Speed=1500、Set Time=1:00:00、Instant Speed=0、Remaining=00:00:00、Instant Temp=当前读数；十字架亮、时钟/圆/▲ 灭、隔断线常显、感叹号不显示。

### TC-SM-02 待机单击旋钮进入设置
- **对应需求**：REQ-SM-02
- **场景类别**：正常流
- **前置条件**：待机
- **操作步骤**：单击旋钮 1 次。
- **预期结果**：SPEED 字段开始闪烁，其余字段常显。

### TC-SM-03 5s 无操作自动确认退出
- **对应需求**：REQ-SM-03, REQ-STOR-04
- **场景类别**：边界值
- **前置条件**：设置中编辑 SPEED，刚完成一次旋转（值已改变）
- **操作步骤**：不再操作，秒表计时观察。
- **预期结果**：5s ±0.5s 后闪烁停止、退出设置、回到待机；断电重启后新值已被保存（写 Flash）。

### TC-SM-04 设置中操作重置 5s 计时
- **对应需求**：REQ-SM-03
- **场景类别**：边界值
- **前置条件**：设置中编辑 SPEED
- **操作步骤**：每 4s 旋转 1 格，持续 30s；随后停止操作。
- **预期结果**：持续旋转期间始终不退出；停止操作后 5s 才退出。

### TC-SM-05 待机按 START 启动
- **对应需求**：REQ-SM-04
- **场景类别**：正常流
- **前置条件**：待机，已设定目标转速 500
- **操作步骤**：按 START。
- **预期结果**：电机启动并向 500 RPM 运行；▲ 亮、转速 >0 时圆亮。

### TC-SM-06 参数闪烁中按 START 启动
- **对应需求**：REQ-SM-04
- **场景类别**：正常流
- **前置条件**：设置中，SPEED 正在闪烁
- **操作步骤**：直接按 START。
- **预期结果**：闪烁立即停止、参数确认写入、电机启动向目标运行。

### TC-SM-07 暂停中按 START 恢复
- **对应需求**：REQ-SM-04
- **场景类别**：正常流
- **前置条件**：运行中按 STOP 进入暂停
- **操作步骤**：按 START。
- **预期结果**：电机重新启动向原目标运行；倒计时从冻结值继续（见 A11）。

### TC-SM-08 运行中 STOP 暂停
- **对应需求**：REQ-SM-05
- **场景类别**：正常流
- **前置条件**：运行中，倒计时进行中（Remaining=00:30:00）
- **操作步骤**：按 STOP，观察 10s。
- **预期结果**：电机停转；时钟/圆/▲ 熄灭；Instant Speed 衰减至 0；Remaining 保持 00:30:00 不变；Instant Temp 继续刷新。

### TC-SM-09 运行中单击旋钮进设置电机不停
- **对应需求**：REQ-SM-06
- **场景类别**：正常流
- **前置条件**：运行中，转速稳定在 500
- **操作步骤**：单击旋钮进入设置，保持 10s 不改参数，再按 STOP 暂停。
- **预期结果**：进入设置后 SPEED 闪烁、电机继续按 500 运行不停机；暂停后一切如 TC-SM-08。

### TC-SM-10 暂停后改参数按新参数运行
- **对应需求**：REQ-SM-07
- **场景类别**：正常流
- **前置条件**：运行中（1000 RPM）按 STOP 暂停
- **操作步骤**：1) 单击旋钮进设置，将转速改为 600；2) 按 START。
- **预期结果**：电机按 600 RPM 启动运行；若倒计时被改过则按新值重载（见 A11）。

### TC-SM-11 暂停后不改参数直接 START
- **对应需求**：REQ-SM-07, REQ-TIMER-02
- **场景类别**：正常流
- **前置条件**：运行中倒计时已递减到 00:10:00 时暂停
- **操作步骤**：不进入设置，直接按 START，观察倒计时。
- **预期结果**：从 00:10:00 继续递减（非从设定值重载）；转速为原目标。

## 4. 电机与测速域用例

### TC-MOT-01 各档位闭环稳定
- **对应需求**：REQ-MOT-01
- **场景类别**：正常流
- **前置条件**：速度环已接入（SPEED_LOOP_EN=1，Kp/Ki 已整定；LUT 可用验证映射，PI 兑底）；测速链路通（PB4/EXTI4，PPR=18）
- **操作步骤**：依次设定 100、500、1000、2000 并启动，各稳定 30s 记录实测转速（shell pid 观察）。
- **预期结果**：各档位稳态实测转速与目标偏差 ≤ ±50 RPM（A12 容差），无振荡、无停转；输出占空比不超过 SPEED_LOOP_DUTY_MAX。

### TC-MOT-02 Instant Speed 与实测一致
- **对应需求**：REQ-MOT-02
- **场景类别**：正常流
- **前置条件**：测速链路已通（PB4/EXTI4，2026-09-14 验证通过），SPEED_PPR=18 已标定（2026-09-15）
- **操作步骤**：以 500 RPM 运行，对比 Instant Speed 与外部转速计，观察 30s。
- **预期结果**：显示值与参考值偏差 ≤ ±5%，刷新连续（约 5 次/s，无长时间卡值）。

### TC-MOT-03 到达判定为信息事件（不驱动倒计时）
- **对应需求**：REQ-MOT-03, REQ-TIMER-01
- **场景类别**：正常流
- **前置条件**：目标 1000 RPM、时间 00:01:00
- **操作步骤**：按 START（倒计时应立即开始），观察转速到达目标（1000±50 持续 1s）瞬间的显示与计时。
- **预期结果**：倒计时在 START 后即开始递减，与转速到达无关；到达瞬间 Remaining/图标/电机无任何跳变（到达事件仅内部发布、无可见副作用）。

### TC-MOT-06 闭环动态响应（启动无振荡 + STOP 后重启动无冲击）
- **对应需求**：REQ-MOT-01
- **场景类别**：正常流
- **前置条件**：闭环已接入；目标 1000 RPM、时间 00:05:00
- **操作步骤**：1) STANDBY 下按 START，用 shell pid 每 500ms 记录 meas/ref/duty 直至稳定；2) 运行中调至 1500，再观察 10s；3) 按 STOP，1s 内立即再按 START，观察启动曲线。
- **预期结果**：启动后实测转速单调逼近目标（允许一次轻微超调，无持续振荡）；全程占空比连续无阶跃突变、不超过限幅；目标变更后平滑过渡，电机不停止；**STOP 后立即再启动时 ref 从实测转速起飞、duty 无冲击跳变（不出现大电流猛启动；2026-09-17 修复回归）**。

### TC-MOT-04 STOP 后转速显示衰减至 0
- **对应需求**：REQ-MOT-04, REQ-ICON-03
- **场景类别**：正常流
- **前置条件**：运行中转速 1000
- **操作步骤**：按 STOP，观察 Instant Speed 与圆图标。
- **预期结果**：电机停转，Instant Speed 由 1000 连续衰减至 0（不瞬时跳 0）；圆图标在转速归 0 时熄灭。

### TC-MOT-05 运行中改转速平滑跟随
- **对应需求**：REQ-MOT-05
- **场景类别**：正常流
- **前置条件**：运行中转速稳定 500，进入设置编辑 SPEED
- **操作步骤**：顺时针旋转 10 格（500→600），观察电机与占空比变化。
- **预期结果**：每格旋转后实际转速平滑上升至新值；全程无停机、无阶跃突变（观察电流/PWM 波形连续）。

## 5. 温度域用例

### TC-TEMP-01 温度精度与 0.1℃ 分辨率
- **对应需求**：REQ-TEMP-01
- **场景类别**：正常流
- **前置条件**：PT1000 已插入，标准温度计/精密电阻（如 1097.35Ω≈25.0℃）就位
- **操作步骤**：1) 室温稳定环境读数；2) 探头放入冰水混合物（0℃）读数；3) 沸水（100℃，按当地气压修正）读数。
- **预期结果**：三点偏差均 ≤ ±1℃；显示小数位为 0.1℃ 分辨率，读数稳定（波动 ≤0.3℃/10s）。

### TC-TEMP-02 全状态持续刷新
- **对应需求**：REQ-TEMP-02
- **场景类别**：正常流
- **前置条件**：运行中
- **操作步骤**：运行 1min → 暂停 1min → 用手捂探头观察显示。
- **预期结果**：运行与暂停期间温度均持续刷新（≤1s 周期），手捂后数值明显变化。

### TC-TEMP-03 待机拔插探头联动
- **对应需求**：REQ-TEMP-03, REQ-ICON-01
- **场景类别**：正常流
- **前置条件**：待机，探头已插入
- **操作步骤**：1) 拔出探头观察 2s；2) 插回观察 2s。
- **预期结果**：拔出 → 温度整块隐藏 + 十字架灭（≤1s）；插回 → 恢复显示 + 十字架亮（≤1s）。

### TC-TEMP-04 运行中拔出探头
- **对应需求**：REQ-TEMP-02, REQ-TEMP-03, REQ-ICON-01
- **场景类别**：异常流
- **前置条件**：运行中倒计时进行中
- **操作步骤**：运行中拔出 PT1000，观察 10s 后插回。
- **预期结果**：温度整块隐藏 + 十字架灭；电机与倒计时不受影响；插回后恢复显示与图标。

## 6. 倒计时域用例

### TC-TIMER-01 START 即开始倒计时
- **对应需求**：REQ-TIMER-01
- **场景类别**：正常流
- **前置条件**：目标 2000 RPM（加速时间明显）、时间 00:00:30
- **操作步骤**：按 START，观察 Remaining Time 与时钟图标（含加速段）；随后按 STOP 观察。
- **预期结果**：按 START 后 ≤1s 内 Remaining 从 00:00:30 开始逐秒递减（不再等待转速到达）；时钟图标亮；按 STOP 立即冻结保持当前值。

### TC-TIMER-02 每秒精确递减
