# 需求细分拆解 — ES 电机驱动板

> **定位**：本文档是开发的唯一指导文档。完成的定义 = 完全覆盖《产品需求简述》的全部内容。
> **上游依据**：`doc/产品需求简述.md`（含 docx 原文摘录）、`doc/产品认知摘要.md`（歧义与假设清单 A1~A17）。
> **下游**：《详细测试用例.md》（每 REQ ≥ 1 条 TC）、《软件架构设计.md》（每 REQ 有模块落点）。
>
> **编号规则**：`REQ-<域>-<序号>`，域：DISP 显示 / IN 输入 / SM 状态机 / MOT 电机与测速 / TEMP 温度 / TIMER 倒计时 / ICON 图标 / STOR 存储 / SYS 系统级。
> **优先级**：P0 = 必须（缺失则产品不可用）；P1 = 应该（重要但可后期补）；P2 = 可选（预留/增强）。
> **假设标注**：涉及文档歧义的条目标注 `[ASSUMPTION An]`，编号与《产品认知摘要》第 4 节一致。
> **需求总量**：47 条。覆盖性核对表见文末附录 B。

## 1. 显示域（DISP）

### REQ-DISP-01 界面布局
- **描述**：屏面由 4 组数据区（Set Speed；Set Time；Instant Speed + Instant Temp；Remaining Time）、右上角图标区与常显隔断线组成。
- **来源**：简述 一「OLED 显示屏 显示 4 组数据区…+ 右上角 5 个状态图标区」；简述 三A-1「屏幕驱动与界面布局（4 数据区 + 图标区 + 隔断线常显）」。
- **验收标准**：上电后目视可见全部 4 组数据区标签与数字区、图标区、隔断线常亮（任何状态下）。
- **优先级**：P0
- **假设**：无（图标数量按 [ASSUMPTION A16] 计 6 个）。

### REQ-DISP-02 转速字段格式
- **描述**：Set Speed 与 Instant Speed 均以 4 位数字 + `Rpm` 单位段显示，数字右对齐，高位空位熄灭。
- **来源**：简述 三A-2「字段格式化：转速 4 位 + "Rpm"」。
- **验收标准**：设定/显示 2000 → `2000Rpm`；100 → 高两位熄灭 + `100Rpm`；单位段 `Rpm` 常显。
- **优先级**：P0
- **假设**：无。

### REQ-DISP-03 时间字段格式
- **描述**：Set Time 与 Remaining Time 按 `H(≤4位) m(2位) s(2位)` 显示，H/m/s 单位段按屏丝印点亮。
- **来源**：简述 三A-2「时间 HHHH H MM m SS s」；docx「倒计时时间最大：9999.59.59」。
- **验收标准**：设定 1:23:45 → H=0001、m=23、s=45；设定 9999:59:59 → 全字段正确显示；单位段常显。
- **优先级**：P0
- **假设**：无。

### REQ-DISP-04 温度字段格式
- **描述**：Instant Temp 按 `888.8℃` 格式显示（3 位整数 + 小数点 + 1 位小数 + ℃ 单位段）。
- **来源**：简述 一「PT1000 测温探头…格式 888.8℃」；简述 三A-2「温度 888.8℃」。
- **验收标准**：25.6℃ → 显示 ` 25.6℃`（高位空位熄灭）；小数位与 ℃ 段正确点亮。
- **优先级**：P0
- **假设**：无。

### REQ-DISP-05 编辑参数闪烁
- **描述**：进入设置后，当前编辑字段以 500ms 周期闪烁（亮/灭交替）；确认（单击跳字段 / 按 START / 5s 超时）后停止闪烁。
- **来源**：简述 二.2「数值闪烁」「任一参数闪烁 5 秒无操作 → 自动确认写入，停止闪烁」；简述 三A-3。
- **验收标准**：编辑字段按约 0.5s 周期可视闪烁，非编辑字段不闪烁；确认后闪烁停止且字段显示新值。
- **优先级**：P0
- **假设**：无。

### REQ-DISP-06 温度整块隐藏
- **描述**：PT1000 拔出时，Instant Temp 的 `888.8℃` 数字连同标签整块熄灭；探头插回后恢复显示当前温度。
- **来源**：简述 三A-4；docx「如果拔掉了PT1000，字符"instant temp 888.8°C"全不显示」。
- **验收标准**：拔出探头 → 温度数字、标签、℃ 段全部熄灭；插回 → 恢复显示且数值为当前读数。
- **优先级**：P0
- **假设**：无（隐藏判定依赖 REQ-TEMP-03 开路检测）。

### REQ-DISP-07 图标渲染联动
- **描述**：图标区渲染由系统状态事件驱动，状态逻辑遵循 REQ-ICON-01 ~ REQ-ICON-06。
- **来源**：简述 三A-5「图标渲染与状态联动（见 E）」。
- **验收标准**：图标状态变化与对应状态事件一致（以 REQ-ICON 系列验收标准为准）。
- **优先级**：P0
- **假设**：无。

## 2. 输入域（IN）

### REQ-IN-01 旋钮旋转解码
- **描述**：EC11 正交解码（4 倍频），顺时针产生 +1 增量、逆时针产生 −1 增量，带去抖；增量只作用于当前编辑字段。
- **来源**：简述 一「旋转=改参数（顺时针增大/逆时针减小）」；简述 三B-6「编码器旋转解码（CW+/CCW−、防抖、只作用于当前闪烁参数）」。
- **验收标准**：每格旋转对应 +1/−1 增量（speed 字段 ±10 RPM）；快速连续旋转不丢步、不误判方向。
- **优先级**：P0
- **假设**：无。

### REQ-IN-02 旋钮单击切换字段
- **描述**：非编辑状态下单击旋钮进入设置并编辑 SPEED；编辑状态下单击确认当前字段并切换到下一字段，循环顺序 SPEED → TIME_H → TIME_M → TIME_S → SPEED。
- **来源**：简述 一「单击=确认并跳到下一个参数」；简述 三B-7「旋钮短按：确认并跳下一参数（speed → time → speed 循环）」。
- **验收标准**：连续单击 4 次完成一个字段循环；每次单击后闪烁位置与顺序一致。
- **优先级**：P0
- **假设**：时间分位循环按 [ASSUMPTION A2]；进入设置的完整路径见 REQ-SM-02/06/07。

### REQ-IN-03 START 键扫描去抖
- **描述**：START 键（PA2，低有效）扫描去抖，按下沿产生唯一"开始"事件，长按不重复触发。
- **来源**：简述 三B-8「START / STOP 按键扫描去抖」；docx「"开始"设置为参数后，按下开始工作」。
- **验收标准**：单次按下只产生 1 次事件；连按/抖动不产生重复或漏触发；长按 3s 以上仍只触发 1 次。
- **优先级**：P0
- **假设**：无。

### REQ-IN-04 STOP 键扫描去抖
- **描述**：STOP 键（PD7，低有效）扫描去抖，按下沿产生唯一"停止/暂停"事件。
- **来源**：简述 三B-8；docx「"停止"运动中停止」。
- **验收标准**：同 REQ-IN-03 的判定方式。
- **优先级**：P0
- **假设**：无。

### REQ-IN-05 转速范围与步进
- **描述**：目标转速范围 100 ~ 2000 RPM，步进 10 RPM。
- **来源**：简述 三B-9「数值范围约束：转速 100/200~2000、步进 10rpm」；docx「电机转速范围：100/200~2000，加减最小细分10rpm」。
- **验收标准**：每次旋转 ±10 RPM；最小可设定 100、最大 2000；中间值可精确到达（如 1010）。
- **优先级**：P0
- **假设**：下限取 100 见 [ASSUMPTION A1]。

### REQ-IN-06 时间范围与编辑
- **描述**：倒计时时间上限 9999:59:59；H（0~9999）、M（0~59）、S（0~59）分位独立编辑。
- **来源**：简述 三B-9「时间上限 9999:59:59」；docx「倒计时时间最大：9999.59.59」。
- **验收标准**：可设定并显示 9999:59:59；各分位可独立加减。
- **优先级**：P0
- **假设**：分位编辑见 [ASSUMPTION A2]；边界行为见 REQ-IN-07 与 [ASSUMPTION A6]。

### REQ-IN-07 编辑边界与非编辑态行为
- **描述**：转速到边界后继续旋转保持钳位（不循环）；H 钳位 0~9999；M/S 在 0~59 循环；非编辑状态下旋转旋钮无效。
- **来源**：文档未定义（歧义缺失项）。
- **验收标准**：在 100 处逆时针、2000 处顺时针，数值保持不变；M/S 59 再加变 0、0 再减变 59；待机/运行非编辑态旋转，所有参数与显示不变。
- **优先级**：P1
- **假设**：[ASSUMPTION A6]、[ASSUMPTION A17]。

## 3. 主状态机域（SM）

### REQ-SM-01 状态集合
- **描述**：系统状态由主模式（STANDBY / RUNNING / PAUSED）与编辑叠加层（EDIT_NONE / EDIT_SPEED / EDIT_TIME_H / EDIT_TIME_M / EDIT_TIME_S）正交组成；编辑层可在任一主模式下激活。
- **来源**：简述 三C-10「主状态机：待机 → 参数编辑（speed/time 子状态）→ 运行 → 运行中编辑 → 停止/暂停」。
- **验收标准**：任何时刻系统处于且仅处于一个主模式 + 一个编辑层状态（共 3×5=15 组合），观察行为与状态定义一致。
- **优先级**：P0
- **假设**：无。

### REQ-SM-02 进入设置
- **描述**：非编辑状态下单击旋钮 → 进入编辑层，SPEED 字段闪烁（待机/暂停/运行中均可用；运行中电机保持原目标运行）。
- **来源**：简述 二.2、二.4、二.5；docx「首次开机，单击旋钮，进入Set speed设置」。
- **验收标准**：待机单击 → SPEED 闪；暂停单击 → SPEED 闪；运行中单击 → SPEED 闪且电机不停止。
- **优先级**：P0
- **假设**：无。

### REQ-SM-03 5s 无操作自动确认
- **描述**：编辑状态下 5s 无任何操作（旋转/单击均重置计时）→ 自动确认写入、停止闪烁、退出编辑层（回到进入前的主模式）。
- **来源**：简述 二.2、三C-13；docx「如果参数闪烁5s，也表示确认参数写入，停止闪烁」。
- **验收标准**：最后一次操作后 5s ±0.5s 停闪退出；旋转或单击后重新计时满 5s 才退出；退出后参数已持久化。
- **优先级**：P0
- **假设**：无。

### REQ-SM-04 START 全局启动
- **描述**：任意状态（含参数闪烁中）按 START → 立即启动/恢复运行：确认写入、停止闪烁、退出编辑层、电机向目标转速运行。
- **来源**：简述 三C-11「全局规则：任意闪烁状态下按 START 即启动」；docx「不管它在哪个参数在闪，只要按了开始，然后它就能启动」。
- **验收标准**：待机/设置中/暂停三种时刻按 START 均能启动或恢复，闪烁立即停止，无延迟。
- **优先级**：P0
- **假设**：无。

### REQ-SM-05 运行中 STOP 暂停
- **描述**：RUNNING 状态下按 STOP → 进入 PAUSED：电机停转、倒计时冻结、时钟/圆/▲ 图标熄灭、实时温度继续显示、实时转速衰减显示至 0。
- **来源**：简述 二.5；docx「运动中单击停止键，设备电机停止…倒计时的时间暂停」。
- **验收标准**：按 STOP 后电机停转（PWM 输出归零），图标按上述联动，剩余时间保持按下时刻的值不变。
- **优先级**：P0
- **假设**：转速显示衰减见 [ASSUMPTION A9]。

### REQ-SM-06 运行中进入设置（电机不停）
- **描述**：RUNNING 状态下单击旋钮 → 进入编辑层，电机按原目标继续运行；退出编辑层前电机行为不受编辑影响（除 SPEED 实时跟随，见 REQ-MOT-05）。
- **来源**：简述 二.4；docx「运行中，按下旋钮键，进入设置参数界面」。
- **验收标准**：进入/退出编辑层全程电机不停止；不改参数时实际转速无变化。
- **优先级**：P0
- **假设**：无。

### REQ-SM-07 暂停后的转换路径
- **描述**：PAUSED 状态下：单击旋钮 → 进入设置，改了哪个参数就按哪个新参数执行；直接按 START → 按当前目标继续工作。
- **来源**：简述 三C-12「停止 → 进设置 → 改参数 → 再启动的转换路径」；docx「改了其中的参数就按新参数重新运行，直接点开始键，就开始工作」。
- **验收标准**：暂停中改转速后 START → 按新转速运行；暂停中改时间后 START → 倒计时按新值重载；未改直接 START → 按原目标继续（倒计时从冻结值继续，见 A11）。
- **优先级**：P0
- **假设**：[ASSUMPTION A11]。

### REQ-SM-08 上电初始状态
- **描述**：上电 → STANDBY，不自动启动；回显上次目标转速/时间；实时转速 0、倒计时 0、实时温度当前读数；图标：十字架按探头实况、时钟/圆/▲ 灭、隔断线常显、感叹号不显示。
- **来源**：简述 二.1、二.6；docx「二次开机…客户直接点击开始键，设备可以直接开始工作」。
- **验收标准**：上电后电机不转，显示与图标状态符合上述，按 START 即可直接启动。
- **优先级**：P0
- **假设**：无。

## 4. 电机控制与测速域（MOT）

### REQ-MOT-01 转速闭环控制
- **描述**：目标转速 100~2000 RPM、分辨率 10 RPM；闭环使实际转速稳定跟随目标（PWM 10kHz、TIM1_CH2；RPM-占空比 LUT 标定）。
- **来源**：简述 三D-14「转速闭环控制（目标范围、10rpm 分辨率）」；docx「电机转速范围：100/200~2000，加减最小细分10rpm」。
- **验收标准**：各档位（如 100/500/1000/2000）稳态下实测转速在标定容差内（±5% 或标定值）；10 RPM 一档变化可分辨。
- **优先级**：P0
- **假设**：[ASSUMPTION A1]。

### REQ-MOT-02 光电测速
- **描述**：采集光耦脉冲信号，按每转脉冲数换算 RPM，滤波后刷新 Instant Speed。
- **来源**：简述 一「光电测速 检测电机实际转速，推算实时 RPM」；简述 三D-15「光电信号测速、RPM 推算与滤波」；docx「instant speed实时检测速度，由光电信号检测推算」。
- **验收标准**：低速手转电机与运行状态下，Instant Speed 与外部参考转速计一致（±容差），刷新连续无明显跳变。
- **优先级**：P0
- **假设**：每转脉冲数配置见 [ASSUMPTION A10]。

### REQ-MOT-03 到达目标判定
- **描述**：实际转速达到目标值（|实际−目标| ≤ 容差且持续 ≥ 稳定时间）→ 置位"已到达"，触发倒计时启动。
- **来源**：简述 二.3「实际转速到达目标值后，剩余时间才从设定值开始倒计时」；简述 三D-16。
- **验收标准**：转速未达目标时倒计时不动；到达后 ≤1s 内倒计时开始递减。
- **优先级**：P0
- **假设**：[ASSUMPTION A12]（容差 50 RPM / 持续 1s，初值）。

### REQ-MOT-04 停止控制
- **描述**：STOP 后电机受控停转（PWM 归零），Instant Speed 随测速自然衰减显示至 0，圆图标随转速归 0 熄灭。
- **来源**：简述 三D-17「停机控制（STOP 后受控停转，转速显示归 0）」；docx「转速实时显示直到显示0」。
- **验收标准**：按 STOP 后电机停转，Instant Speed 由当前值连续衰减至 0（不瞬时跳 0），圆图标熄灭。
- **优先级**：P0
- **假设**：[ASSUMPTION A9]。

### REQ-MOT-05 运行中目标转速平滑跟随
- **描述**：运行中编辑 SPEED，每步 ±10 RPM 立即更新目标，闭环平滑过渡（斜坡逼近），无停机、无阶跃突变。
- **来源**：简述 三D-18「运行中目标转速变更的平滑跟随」；docx「SPEED参数闪烁，转速根据参数变化」。
- **验收标准**：运行中旋转旋钮，实际转速连续平滑变化至新目标，全程电机不停止、占空比无突变。
- **优先级**：P0
- **假设**：[ASSUMPTION A14]。

## 5. 温度采集域（TEMP）

### REQ-TEMP-01 PT1000 采集
- **描述**：采集 PT1000 分压信号，反推阻值换算温度，分辨率 0.1℃，按 888.8℃ 格式显示。
- **来源**：简述 三F-19「PT1000 采集、0.1℃ 分辨率」；docx「PT1000的实时温度读取」。
- **验收标准**：温度显示与标准温度计（或精密电阻标定）偏差 ≤ ±1℃；最小显示单位 0.1℃。
- **优先级**：P0
- **假设**：无。

### REQ-TEMP-02 全状态实时刷新
- **描述**：待机/设置/运行/暂停所有状态下，温度均按周期持续刷新。
- **来源**：简述 三F-19「全状态实时刷新」；简述 二.5「实时温度继续正常显示」。
- **验收标准**：运行与暂停期间用手温改变探头温度，显示值随之变化（刷新周期 ≤1s）。
- **优先级**：P0
- **假设**：无。

### REQ-TEMP-03 探头在位检测
- **描述**：通过 ADC 开路电压阈值判定探头插入/拔出；拔出 → 温度字段整块隐藏 + 十字架图标灭；插入 → 恢复显示 + 十字架亮。
- **来源**：简述 三F-20「探头在位检测（联动 E/F 的隐藏逻辑）」；docx「"十字架"传感器，插入就亮，不插就不亮」。
- **验收标准**：拔插探头，显示与图标在 ≤1s 内联动切换。
- **优先级**：P0
- **假设**：[ASSUMPTION A5]。

## 6. 倒计时域（TIMER）

### REQ-TIMER-01 启动条件
- **描述**：倒计时仅在"实际转速到达目标值"后启动，启动后每秒递减 1s。
- **来源**：简述 三G-21「启动条件：转速到达目标值后才倒数」；docx「Remaining time 运行后，速度到目标值的开始倒计时」。
- **验收标准**：未到达前 Remaining Time 保持设定值不动；到达后按 1Hz 精确递减。
- **优先级**：P0
- **假设**：[ASSUMPTION A12]。

### REQ-TIMER-02 暂停保持
- **描述**：STOP 后倒计时暂停并保持当前剩余值，不清零。
- **来源**：简述 三G-22「停止时暂停并保持剩余值」；docx「倒计时的时间暂停」。
- **验收标准**：暂停后等待 ≥10s，Remaining Time 显示值与暂停时刻完全一致。
- **优先级**：P0
- **假设**：无。

### REQ-TIMER-03 运行中改时间刷新
- **描述**：运行中修改时间并确认（单击/5s/START）后，倒计时按新值重载，显示即时刷新；重载后重新评估"已到达"条件。
- **来源**：简述 三G-23「运行中改时间后，退出设置界面时倒计时刷新」；docx「设置了time，也是按实时参数写入…退出设置界面，实时速度和实时倒计时需要更新」。
- **验收标准**：运行中把时间从 00:10:00 改为 00:05:00，确认退出后 Remaining Time 立即显示 00:05:00 并继续递减（若当时已到达目标）。
- **优先级**：P0
- **假设**：[ASSUMPTION A14]。

### REQ-TIMER-04 归零行为
- **描述**：倒计时归零 → 自动停机：电机停转、倒计时保持 0、状态回 STANDBY、设定参数保留；时钟/圆/▲ 图标熄灭。
- **来源**：文档未定义（简述 G-24 缺失项）。
- **验收标准**：归零瞬间电机停转，状态机回到待机；可再次按 START 按原参数重新工作。
- **优先级**：P1
- **假设**：[ASSUMPTION A4]。

## 7. 图标逻辑域（ICON）

### REQ-ICON-01 十字架
- **描述**：十字架图标 = PT1000 探头插入状态：插入亮、拔出灭。
- **来源**：简述 E 图标表「传感器插入检测，插则亮、拔则灭」。
- **验收标准**：与 REQ-TEMP-03 的拔插联动一致。
- **优先级**：P0
- **假设**：[ASSUMPTION A5]。

### REQ-ICON-02 时钟
- **描述**：时钟图标 = 倒计时进行中：亮；其余时刻灭。
- **来源**：简述 E「倒计时进行中亮」；docx「"时钟"开始倒计时时候亮，不倒计时不用」。
- **验收标准**：见 TC-ICON-02（未到达不亮/递减中亮/暂停灭/恢复亮）。
- **优先级**：P0
- **假设**：无。

### REQ-ICON-03 圆
- **描述**：圆图标 = 实际转速 > 0：亮；= 0：灭。
- **来源**：简述 E「转速 >0 亮，=0 灭」；docx「"圆"…转就亮，转速0不亮」。
- **验收标准**：启动加速期间亮起，停止后随转速衰减至 0 熄灭。
- **优先级**：P0
- **假设**：无。

### REQ-ICON-04 感叹号
- **描述**：感叹号图标本版本固定不显示（预留报警位）。
- **来源**：简述 E「感叹号 本版本固定不显示（预留报警位）」；docx「"感叹号"报警，本版本不用，一直不显示」。
- **验收标准**：所有状态下感叹号均不可见。
- **优先级**：P0
- **假设**：[ASSUMPTION A8]。

### REQ-ICON-05 隔断线
- **描述**：隔断线 `----` 在所有状态下常显。
- **来源**：简述 E「隔断线 常显」；docx「"----"隔断线，一直显示」。
- **验收标准**：所有状态下隔断线均可见。
- **优先级**：P0
- **假设**：无。

### REQ-ICON-06 向上图标
- **描述**：▲ 图标在 RUNNING 状态下常亮，其余状态熄灭。
- **来源**：docx「运转图标点亮，向上图标常亮」（启动段）。
- **验收标准**：START 后 ▲ 点亮并保持；STOP/归零后熄灭。
- **优先级**：P1
- **假设**：[ASSUMPTION A7]。

## 8. 参数存储域（STOR）

### REQ-STOR-01 断电保存与回显
- **描述**：目标转速 + 目标时间（H/M/S）持久化于片上 Flash；上电自动恢复并回显。
- **来源**：简述 三H-25「目标转速/时间断电保存（EEPROM/Flash），上电回显」；docx「再次上电开机，显示上次设置的目标…和目标时间」。
- **验收标准**：设置 → 断电 → 上电后 Set Speed/Set Time 与上次一致；可立即 START 工作。
- **优先级**：P0
- **假设**：[ASSUMPTION A3]（无温度参数）。

### REQ-STOR-02 首次上电默认值
- **描述**：Flash 无有效记录（出厂/擦除）时，使用默认参数：转速 100、时间 00:00:00。
- **来源**：简述 二.1「首次上电：显示默认参数」（值未定义）。
- **验收标准**：擦除 Flash 后首次上电显示默认值，且不崩溃、可正常设置。
- **优先级**：P1
- **假设**：[ASSUMPTION A13]。

### REQ-STOR-03 写入磨损均衡
- **描述**：参数写入采用末页 slot 轮转 + 写满整页擦除的磨损均衡策略。
- **来源**：简述 三H-26「写入磨损与掉电保护」。
- **验收标准**：连续修改参数 ≥50 次，数据始终正确；写满 32 槽后自动整页擦除并继续正确保存。
- **优先级**：P1
- **假设**：无。

### REQ-STOR-04 写入时机与掉电保护
- **描述**：确认时机（单击跳字段 / 5s 超时 / 按 START）触发写入；写入过程中断电不损坏既有有效记录（上电按最后有效记录恢复）。
- **来源**：简述 三H-26；docx「参数闪烁5s，也表示确认参数写入」。
- **验收标准**：未确认的修改断电后不生效；确认后修改断电可恢复；写入瞬间反复断电 10 次，参数回退到最近一次完整记录，不出现乱码。
- **优先级**：P1
- **假设**：[ASSUMPTION A15]。

## 9. 系统级域（SYS）

### REQ-SYS-01 非阻塞架构
- **描述**：超级循环 + 协作式任务调度，任何模块不得使用阻塞延时；外设异常（I2C 无响应等）不影响按键/显示等其余功能。
- **来源**：简述 三H-27「非阻塞架构」。
- **验收标准**：模拟 I2C 通信异常时，屏幕刷新与按键响应保持正常，系统不卡死。
- **优先级**：P0
- **假设**：无。

### REQ-SYS-02 看门狗
- **描述**：启用独立看门狗（IWDG），正常运行时周期喂狗；程序跑飞后触发复位。
- **来源**：简述 三H-27「看门狗」。
- **验收标准**：长时间运行（≥24h）无异常复位；人为注入死循环后芯片复位重启。
- **优先级**：P1
- **假设**：无。

### REQ-SYS-03 报警框架预留
- **描述**：预留故障检测接口（超温 / 失速 / 探头脱落候选），本版本只采集与记录，不点亮感叹号。
- **来源**：简述 三H-27「预留报警框架（感叹号图标位）」。
- **验收标准**：故障注入后系统状态可通过调试接口读取，感叹号保持不显示。
- **优先级**：P2
- **假设**：[ASSUMPTION A8]。
