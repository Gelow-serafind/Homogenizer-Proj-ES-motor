ES 电机驱动板 · 需求梳理
一、产品理解（先统一认知）
从界面和 PCB 布局判断，这是一台台式电动驱动设备（带定时、测速、测温功能，类似实验室搅拌/驱动类设备），核心是一块电机驱动控制板，由以下部件构成：
部件	作用	
OLED 显示屏	显示 4 组数据区（Set Speed / Set Time / Instant Speed + Instant Temp / Remaining Time）+ 右上角 5 个状态图标区	
旋转编码器（PCB 丝印 SW）	带按压。旋转=改参数（顺时针增大/逆时针减小），单击=确认并跳到下一个参数	
START / STOP 按键	启动 / 停止（停止兼做"暂停"语义）	
电机	被控对象，目标转速可设，闭环调速	
光电测速	检测电机实际转速，推算实时 RPM	
PT1000 测温探头（PCB 丝印 PT1）	外插探头，测实时温度，格式 888.8℃	
二、产品视角：整机工作流程与各部位响应
1. 上电待机
首次上电：显示默认参数；再次上电：自动恢复上次设置的目标转速、目标时间（参数断电保存）。
屏幕初始状态：目标转速/目标时间 = 上次设定值；实时转速 = 0；剩余时间 = 0；实时温度 = PT1000 当前读数。
右上角图标：十字架按传感器插入状态亮/灭；时钟、圆熄灭；隔断线常显；感叹号本版本永不显示。
设备等待设置参数，或直接按"开始"一键启动。
2. 参数设置（待机/运行中均可进入）
单击旋钮 → 进入 Set Speed 编辑，数值闪烁；
旋转旋钮 → 顺时针 +、逆时针 −，步进 10rpm，范围 100(或200)~2000rpm；
再单击 → 确认转速，自动跳到 Set Time 编辑（H-M-S）闪烁；
再单击 → 确认时间，循环回到 Set Speed，如此往复；
任一参数闪烁 5 秒无操作 → 自动确认写入，停止闪烁。
3. 启动运行
任意时刻按"开始"（哪怕参数还在闪）→ 立即启动：闪烁停止，电机向目标转速运行；
电机转动后：圆图标点亮（运转标志）、时钟图标点亮；实时转速由光电信号推算并刷新；
实际转速到达目标值后，剩余时间才从设定值开始倒计时（未到达前倒计时不启动）。
4. 运行中在线调节
运行中按下旋钮 → 进入参数界面，SPEED 闪烁；旋转旋钮修改目标转速，电机实际转速立即跟随变化；
若修改 time，同样 5 秒后自动写入生效；
退出设置界面后，实时速度与实时倒计时按新参数刷新。
5. 停止 / 暂停
运行中按"停止" → 电机停转：时钟、圆图标熄灭；实时转速显示 0；剩余时间暂停并保持当前值（不清零）；实时温度继续正常显示；
停止后单击旋钮 → 进入设置，改了哪个参数就按新参数执行；直接按"开始" → 按当前目标值重新开始工作。
6. 断电恢复
上次参数保存并回显；实时转速 0、倒计时 0、时钟/圆图标不显示、传感器图标按实际情况；
用户直接按"开始"即可按上次参数直接工作。
三、软件开发需求点
A. 显示模块
屏幕驱动与界面布局（4 数据区 + 图标区 + 隔断线常显）；
字段格式化：转速 4 位 + "Rpm"；时间 HHHH H MM m SS s；温度 888.8℃；
编辑参数闪烁效果，5s 超时停闪（自动写入）；
PT1000 拔出时，"Instant Temp 888.8℃"连同标签整块隐藏；
图标渲染与状态联动（见 E）。
B. 输入模块
6. 编码器旋转解码（CW+/CCW−、防抖、只作用于当前闪烁参数）；
7. 旋钮短按：确认并跳下一参数（speed → time → speed 循环）；
8. START / STOP 按键扫描去抖；
9. 数值范围约束：转速 100/200~2000、步进 10rpm；时间上限 9999:59:59。
C. 状态机
10. 主状态机：待机 → 参数编辑（speed/time 子状态）→ 运行 → 运行中编辑 → 停止/暂停；
11. 全局规则：任意闪烁状态下按 START 即启动；
12. 停止 → 进设置 → 改参数 → 再启动的转换路径；
13. 5s 无操作自动确认逻辑。
D. 电机控制与测速
14. 转速闭环控制（目标范围、10rpm 分辨率）；
15. 光电信号测速、RPM 推算与滤波；
16. "实际转速到达目标值"判定（触发倒计时 + 圆图标）；
17. 停机控制（STOP 后受控停转，转速显示归 0）；
18. 运行中目标转速变更的平滑跟随。
E. 图标逻辑
图标	逻辑	
十字架	传感器插入检测，插则亮、拔则灭	
时钟	倒计时进行中亮	
圆	转速 >0 亮，=0 灭	
感叹号	本版本固定不显示（预留报警位）	
隔断线	常显	
F. 温度采集
19. PT1000 采集、0.1℃ 分辨率、全状态实时刷新；
20. 探头在位检测（联动 E/F 的隐藏逻辑）。
G. 倒计时
21. 启动条件：转速到达目标值后才倒数；
22. 停止时暂停并保持剩余值；
23. 运行中改时间后，退出设置界面时倒计时刷新；
24. 倒计时归零后的行为（文档缺失，见下）。
H. 参数存储与系统级
25. 目标转速/时间断电保存（EEPROM/Flash），上电回显；首次上电默认值；
26. 写入磨损与掉电保护；
27. 非阻塞架构、看门狗、预留报警框架（感叹号图标位）。
四、文档疑点（建议开发前确认）
转速下限是 100 还是 200？"100/200~2000"表述歧义；
"二次开机显示上次设置的目标温度"——本机没有 Set Temp 参数，疑为笔误（应为目标时间）；同理"再次从 set temp 开始"疑为 set speed；
时间编辑粒度：H/M/S 分位编辑还是整体加减？单击旋钮在时间上加减多少？
停止后再启动：倒计时从暂停的剩余值继续，还是从设定值重新开始？（文档"按新参数重新运行"暗示改参数才重置）；
倒计时归零后行为未定义：自动停机？报警？图标状态？
十字架图标对应的是 PT1000 还是光电传感器；
参数到上下限后继续旋转：钳位还是循环回绕；
文档提到启动时"向上图标常亮"，但图标说明表中未定义该图标，需确认；
感叹号未来对应哪些故障类型（超温/失速/探头脱落），建议本版本至少预留判断接口。
