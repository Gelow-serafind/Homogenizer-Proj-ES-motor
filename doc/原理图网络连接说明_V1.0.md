>   - Pin13 `PC3`=MCU_SW_B（旋钮 B 相）｜ Pin14 `PC4`=MCU_SW_PUSH（旋钮按键）｜ Pin15 `PC5`=MCU_SW_A（旋钮 A 相）

## 一、电源与地网络定义

| 网络名 | 来源 | 去向 |
|---|---|---|
| VCC_24V | CN7 电源输入端子（24V，范围 4.3~60V） | 两路 Buck 输入、电机正端、Q1 集电极 |
| VCC_5V | U54（LMR16030，5V/3A 主电源）、U1（ME3116，5V/1A） | MCU、ADS1115、LCD 驱动、上拉电阻等 |
| +5V | 独立网络（图上仅见于速度检测接口区，来源待核对） | U15 速度检测接口供电 |
| GND | 公共地 | 全板 |

## 八、电机驱动电路（Q2 低边 PWM 斩波）

信号链：MCU_2MOTOR_PWM（MCU.3）→ R15(62Ω) → 驱动节点 N1

| 器件 | 引脚/端子 | 连接 |
|---|---|---|
| R15 62Ω | — | MCU_2MOTOR_PWM 与节点 N1 之间 |
| R7 10kΩ | — | 节点 N1 → GND（默认下拉关断） |
| Q1 MMBT5551（NPN） | 基极 | ← 节点 N1（经 R8 10Ω，待核对） |
|  | 集电极 | ← VCC_24V |
|  | 发射极 | → 栅极节点 N2 |
| Q4 MMBT5401（PNP） | 基极 | ← 节点 N1（经 R12 10Ω，待核对） |
|  | 发射极/集电极 | 与 Q1 构成对管：一端 → 栅极节点 N2，另一端 → GND（关断放电通路） |
| R6 20Ω | — | 节点 N2 → Q2 栅极（串联阻尼） |
| D2 1N4148W | — | 与 R6 并联反向（关断时栅极电荷快速泄放） |
| R10 10kΩ | — | Q2 栅极 → GND（GS 下拉保持） |
| D3 BZT52C12（12V 稳压管） | — | Q2 栅极 → 源极（GND），Vgs 钳位 12V 保护 |
| Q2 NCE6080K（N-MOS 60V） | 栅极 G | ← N2 |
|  | 源极 S | → GND |
|  | 漏极 D | → CN1 Pin2（电机负端） |

CN1（DB2EVC-3.5-2P-GN，电机接线端子）：Pin1 = VCC_24V（电机正端，常供）；Pin2 = Q2 漏极（电机负端，被 PWM 斩波调速）。

## 十二、要点备注（含待核对项）

- 系统架构：24V 输入 → 双路 Buck（3A 主电源 + 1A 辅助）→ 5V 系统；MCU 输出 PWM 经三极管推挽驱动 NMOS Q2，对电机做低边斩波调速；ADS1115 采集 PT100 温度；段码 LCD 显示；编码器 + 按键操作。
- I2C：MCU 与 ADS1115 为复用 I2C（ADC_SCL/ADC_SDA），从机地址 0x48（ADDR 接地）。
- 待核对项（图面分辨率所限）：
  1. MCU Pin4 的 ADC_SCL 与 RESET（R1/C1）网络归属；
  2. MCU Pin15（DATA/RD 之一）、Pin8、Pin20 的最终确认；
  3. SPEED_SW 速度信号进 MCU 的具体引脚（图上 U15 区邻近有 USART1_RX 标注，疑似与 PB4 复用）；
  4. +5V 网络（U15 供电）的来源；
  5. U1 自举电容位号（C25）、EN 上拉电阻（R192/R43）的具体接法。
