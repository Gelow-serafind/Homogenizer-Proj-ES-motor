## 2. 用户交互流程

### 2.1 上电待机

- **首次上电**：显示默认参数（默认值文档未定义，按 [ASSUMPTION A13] 取：目标转速 100、目标时间 00:00:00）。
- **再次上电**：自动恢复上次设置的目标转速、目标时间（断电保存）。
- 屏幕初始状态：目标转速/目标时间 = 上次设定值；实时转速 = 0；剩余时间 = 0；实时温度 = PT1000 当前读数。
- 图标初始状态：十字架按探头插入实况亮/灭；时钟、圆 熄灭；隔断线常显；感叹号恒不显示。
- 用户可直接按 START 一键启动，也可单击旋钮先进设置。

### 2.2 参数设置（待机 / 暂停 / 运行中均可进入）

1. 单击旋钮 → 进入设置，SPEED 字段闪烁；
2. 旋转旋钮 → 顺时针 +、逆时针 −，步进 10 rpm，范围 100(或 200，见 A1) ~ 2000；
3. 再单击 → 确认转速，跳到时间字段；时间按 H → M → S 分位编辑（[ASSUMPTION A2]）；
4. 再单击 → 确认时间，循环回 SPEED，如此往复；
5. 任一参数闪烁 5 秒无操作 → 自动确认写入，停止闪烁，退出设置。

### 2.3 启动运行

- 任意时刻（哪怕参数还在闪）按 START → 立即启动：闪烁停止，参数确认写入，电机向目标转速运行。
- 图标变化：圆点亮（RUNNING 且实测转速 >0）、感叹号保持灭、时钟在非零时间 START 后即亮（含加速段，实际倒计时期间）。
- 实时转速由光电信号推算并刷新；**按 START 立即从设定值开始倒计时**（2026-09-17 用户实测决策变更，取代"到达目标后才倒计时"）；按 STOP 暂停冻结。

### 2.4 运行中在线调节

- 运行中按下旋钮 → 进入设置界面（电机保持转动），SPEED 闪烁；旋转修改目标转速，**电机实际转速立即跟随**（[ASSUMPTION A14]）。
- 修改 time：确认（单击 / 5s / START）后生效，退出设置界面时实时倒计时按新值刷新。
- 退出设置界面后，实时速度与实时倒计时按新参数刷新。

### 2.5 停止 / 暂停

- 运行中按 STOP → 电机停转：时钟、圆 图标熄灭；实时转速随测速自然衰减显示直到 0（[ASSUMPTION A9]）；剩余时间**暂停并保持当前值**（不清零）；实时温度继续正常显示。
- 停止后单击旋钮 → 进入设置，改了哪个参数就按哪个新参数执行；直接按 START → 按当前目标重新开始工作。
- 暂停后直接 START 的倒计时语义见 [ASSUMPTION A11]。

### 2.6 断电恢复

- 上次参数保存并回显；实时转速 0、倒计时 0、时钟/圆 图标不显示、传感器图标按实际情况。
- 用户直接按 START 即可按上次参数直接工作。

## 3. 屏幕显示内容与图标状态逻辑

### 3.1 数据区

| 数据区 | 内容 | 格式 | 状态逻辑 |
|---|---|---|---|
| Set Speed | 目标转速 | 4 位数字 + `Rpm` | 编辑时闪烁；确认后常显 |
| Set Time | 目标倒计时 | H(≤4位) + `H`，M(2位) + `m`，S(2位) + `s` | 编辑分位闪烁；其余同左 |
| Instant Speed | 实时转速 | 4 位数字 + `Rpm` | 全状态实时刷新；停止后衰减显示至 0 |
| Instant Temp | 实时温度 | `888.8℃`（3 位整数 + 1 位小数 + ℃） | 全状态实时刷新；**探头拔出时数字连同标签整块熄灭** |
| Remaining Time | 剩余倒计时 | 同 Set Time | **START 后立即递减**（2026-09-17 用户实测决策变更，原"到达目标后"）；暂停冻结；归零见 A4 |
| 图标区 | 右上角 4 个图标（见 3.2） | — | 按状态联动 |
| 隔断线 `----` | 视觉分隔 | — | **常显** |

### 3.2 图标状态逻辑

> 2026-10-08 按屏规格书第 3 页及用户确认纠正：无独立“向上”图标，三角形内部为感叹号。

| 图标 | 亮 | 灭 |
|---|---|---|
| 十字架 S30 | PT1000 在位（A5） | 探头拔出 |
| 时钟 S2 | RUNNING 且倒计时 active | 暂停/待机/零时间运行 |
| 圆 S4 | RUNNING 且实测转速 >0 | 暂停/待机立即灭；运行中零速灭 |
| 感叹号 S3 | 本版不亮（2026-10-08 用户确认） | 所有业务状态 |
| Set Speed 标签 S1 | 全状态常显，数字仅主动编辑时闪烁 | 无 |
| 隔断线 S10~19 | 常显 | 无 |

## 4. 文档歧义点与缺失项清单

> 编号 A1~A17 为全文档体系统一引用的假设编号，处理方式在《需求细分拆解.md》中落地为 `[ASSUMPTION]` 标注。

| # | 歧义 / 缺失 | 涉及原文 | 处理方式（假设与理由） |
|---|---|---|---|
| A1 | 转速下限是 100 还是 200（"100/200~2000"） | docx「电机转速范围：100/200~2000」 | **取 100**：取文档首值，代码以 `RPM_MIN` 常量实现，确认后单点修改即可 |
| A2 | 时间编辑粒度：H-M-S 分位编辑还是整体加减 | docx「设置Set time（H-M-S）。再单击旋钮，表示设置循环」 | **取分位编辑**：单击依次循环 SPEED→H→M→S→SPEED，各分位独立调节；理由：三分位均可达、可测，且与现有实现一致 |
| A3 | "二次开机显示上次设置的目标温度"、"再次从 set temp 开始" | docx「显示上次设置的目标温度和目标时间」 | **判为笔误**：本机无温度设置参数，回显的应为目标转速 + 目标时间 |
| A4 | 倒计时归零后的行为未定义 | 简述 G-24「倒计时归零后的行为（文档缺失）」 | **归零 → 自动停机、倒计时保持 0、状态回待机、参数保留**（可再次 START 重载） |
| A5 | 十字架图标对应 PT1000 还是光电传感器 | docx「"十字架"传感器，插入就亮」 | **取 PT1000 探头**：原文图标段与温度段同处描述"传感器插入状态"；光电测速无"插入"概念 |
| A6 | 参数到上下限后继续旋转：钳位还是循环回绕 | 文档未定义 | **转速钳位**（100/2000 不动）；**H 钳位**（0~9999）；**M/S 循环**（0↔59，时钟编辑惯例） |
| A7 | “向上图标常亮”旧推断 | 原文启动段 | **2026-10-08 纠正**：规格图无独立箭头；S3 是警告三角感叹号，按 A8 恒灭；不得再绑定运行状态 |
| A8 | 故障范围未定义 | 原文及 2026-10-08 用户回复 | **本版本感叹号 S3 恒灭，不新增故障判断**；报警框架仍属未来预留 |
| A9 | STOP 后速度显示方式 | docx「转速实时显示直到显示0」 | 数字按实测衰减至 0；**圆图标按 2026-10-08 用户决策在暂停时立即灭** |
| A10 | 光电传感器每转脉冲数未知 | 简述 D-15 | **已实测：18 脉冲/圈**（2026-09-15 上板手转标定：1圈=18、2圈=36、7圈=126），写入 `SPEED_PPR`（app_cfg.h） |
| A11 | 停止后再启动：倒计时从剩余值继续还是重载 | docx「改了其中的参数就按新参数重新运行」「中途按了暂停…设置参数是保持之前设定的目标值」 | **未改时间 → 从冻结剩余值继续；改过时间 → 按新设定值重载**（"改参数才重置"） |
| A12 | "到达目标转速"的判定阈值与持续时间 | 简述 D-16 | **\|实际−目标\| ≤ 50 RPM 且持续 ≥ 1s 判定到达**（初值，标定后调整）。**2026-09-17 起仅作信息事件（post EVT_REACH_TARGET，无消费方）：倒计时改为 START 直启** |
| A13 | 首次上电默认参数值未定义 | 简述 二.1「首次上电：显示默认参数」 | **默认转速 100、默认时间 00:00:00**（常量实现，可改） |
| A14 | 运行中改 SPEED 是否每步实时生效；改 TIME 何时生效 | docx「SPEED参数闪烁，转速根据参数变化」「设置了time…5s后自动写入」 | **SPEED 每步立即生效；TIME 确认（单击/5s/START）后生效并刷新倒计时** |
| A15 | "自动确认写入"是否指写入 Flash | docx「参数闪烁5s，也表示确认参数写入」 | **确认即持久化**：单击跳字段 / 5s 超时 / 按 START 三种时机均写 Flash |
| A16 | 图标数量旧推断 | 原文 + 屏规格书第 3 页 | **右上角 4 个图标**（十字架/时钟/感叹号/圆）+ 隔断线；S1 为 Set Speed 标签，无独立 ▲ |
| A17 | 非编辑状态下旋转旋钮的行为未定义 | docx 仅描述设置中旋转 | **非编辑态旋转无效**（不改变任何参数），避免待机误改参数 |
