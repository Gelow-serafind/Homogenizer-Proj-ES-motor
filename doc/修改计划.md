## 0. 结论总览

新原理图与当前代码相比是**全新硬件平台**：

| 维度 | 结论 |
|---|---|
| 电机 PWM | 引脚由 PD2 改为 **PD6**（TIM1_CH2，AF3），且**必须删除**原 IOMUX 重映射调用 |
| UART | TX/RX 由 PA3/PD6 改为 **PD4/PB4**（AF1） |
| 编码器 | A/B/按键由 PC3/PC4/PC5 改为 **PC5/PC3/PC4**；按键极性由**低有效改为高有效** |
| 按键 | 新增独立**开始键 PA2、停止键 PD7**（均低有效、外部 10k 上拉） |
| 显示屏 | 驱动芯片由 **TM1729（2 线类 I2C）整体更换为 HT1623（4 线串行 + IRQ）**，驱动需完全重写 |
| 新增外设 | **ADS1115 外置 16 位 ADC**（I2C，0x48）：AIN0=PT1000 温度、AIN1=光耦测速 |
| MCU 供电 | VDD=**5V**（芯片允许 2.4~5.5V），所有 IO 均为 5V 电平 |
| 业务 | 状态机、转速范围/步进、倒计时、温度、实时测速、图标、持久化 **全部与需求不符，需重构** |

### 1.3 电路其他要点（无代码影响，供理解）

- 电源：24V 输入 → LMR16030 降压 → 5V（R189/R190 分压）；ME3116 备用 5V；PW_EN 由 R192 固定使能。
- 电机驱动链：`MCU_2MOTOR_PWM`（高有效）→ Q1 NPN / Q4 PNP 推挽 → Q2 NCE6080K 门极（R15 62Ω；D2 1N4148W、D3 12V 齐纳保护）→ 低边开关电机。**PWM 高电平 = 电机通电**，与当前代码 PWM1+High 语义一致。
- LCD 背光：5V → R9 33Ω → LED+（3V/60mA）常亮，无 MCU 控制。
- HT1623：OSCI/OSCO 外接 32kHz 晶振；VLCD 由 R5(0Ω)/R182(10k) 分压（调节对比度）；BZ、T1~T3 悬空不用。
- ADS1115：ADDR=GND → I2C 地址 0x48；ALERT/RDY 仅经 R17 4.7k 上拉，**未接 MCU**（MCU 18 个 IO 已全部占用），故采用连续转换 + 轮询方式读取。
- 芯片 TSSOP20 全引脚为原生映射，**无需任何 IOMUX 配置**。

## 2. 业务差异：需求 vs 当前代码

### 2.1 状态机

| 项 | 当前代码 | 需求 |
|---|---|---|
| 模式 | STOPPED / RUNNING 双模式，**长按 3 秒**切换启停 | **单击旋钮**进入设置（Set Speed → 单击 → Set Time → 单击循环）；**开始键**启动、**停止键**暂停；运行中**按旋钮**可进入设置 |
| 设置确认 | 无（旋钮直改转速） | 参数闪烁 5s 自动确认写入；按开始键也立即生效 |
| 暂停 | 无独立概念（停止=转速清零） | 暂停：电机停、倒计时冻结、实时转速显示递减到 0、图标熄灭；再点开始按原参数继续 |
| 上电 | 恢复上次转速 | 恢复上次目标转速+时间；实时温度为当前读数、实时转速 0、倒计时 0；点开始键可直接工作 |

> 注：需求描述的四态行为（STANDBY/SETTING/RUNNING/PAUSED）与仓库 `README.md` 中旧版状态机描述一致——即当前 `main.c` 是相对需求**退化**的版本。

### 2.2 转速与驱动

| 项 | 当前代码 | 需求 |
|---|---|---|
| 转速范围 | 5000~20000 RPM | **100（或 200，待确认）~2000 RPM** |
| 旋钮步进 | 1000 RPM，0↔5000 跳变 | **10 RPM** |
| **PWM 控制频率** | **17.57kHz**（`PWM_TARGET_FREQ_HZ = 17570`） | **10kHz**（已确认，需修改：48MHz 时钟下 ARR = 4799，占空比分辨率约 0.02%，满足细分要求） |
| RPM-占空比表 | 旧电机实测（5000 起） | **新电机需重新标定** 100~2000 RPM 曲线 |
| 实时转速 | 无（开环斜坡 MotorRpm） | 光耦传感器实时检测并显示；**到达目标转速后开始倒计时** |
| 运行中改转速 | 直接生效 | 设置界面中 SPEED 闪烁，**转速随参数实时变化**；退出后实时值刷新 |

## 3. 修改计划（分阶段）

### P1 — 引脚与外设配置迁移（main.c 头部宏 + 配置函数）

1. 重写 `main.c` 顶部引脚宏：EC11→PC5/PC3/PC4；LCD→PD3/PD2/PD1/PC6(PC7)；KEY_START→PA2；KEY_STOP→PD7。
2. `TIM1_PWM_Config()`：GPIOD `GPIO_Pin_6`、AF3；**删除 `GPIO_IOMUX_ChangePin` 调用**；`PWM_TARGET_FREQ_HZ` 由 17570 改为 **10000（10kHz）**，ARR = 48MHz/10kHz − 1 = **4799**。10kHz 下驱动链（Q1/Q4 推挽 + Q2 门极）无任何问题，仅重算 ARR 即可。
3. `UART_Config()`：更新 EVAL 板宏（TX=PD4 AF1，RX=PB4 AF1，时钟改 `RCC_AHBPeriph_GPIOD/GPIOD/GPIOD/GPIOD`）。
4. `EC11_Config()`：PC3/PC4/PC5 改下拉输入（外部已有 10k 下拉）；按键极性反转为高有效。
5. 新增 `KeyStart/KeyStop` 输入配置（PA2/PD7，上拉输入，低有效）与消抖。
6. 新增 I2C：优先硬件 I2C（PA1/PA3，AF0，400kHz，参考 EVAL 板 `sEE` 例程）；保留软件 I2C 备选实现。
7. `hk32f0301mxxc_conf.h` 无需变更（I2C 模块头已包含）。

### P2 — HT1623 显示驱动（完全重写，替代 TM1729 全部代码）

1. 删除 `TM1729_*` 全部函数与 `TM1729_BitBuf` 逻辑（约 300 行）。
2. 按 Holtek HT1623 数据手册实现 4 线串行协议：CS/WR/DATA（RD 常高）；命令字 SYS EN/LCD ON/BIAS/RC 256k；48 SEG × 8 COM RAM 全量写（0xA0+地址）。
   - **行动项：向硬件/屏厂索取 HT1623 数据手册**，核对命令码（BIAS、OSC、占空比选择）。
3. 依据玻璃规格书第 3 页引脚表，建立 24 数码位 + S1~S30 图标的 `SEG/COM → 位` 映射表（写段码查找表）。
4. 显示层接口：`Lcd_ShowField(field, value)`、`Lcd_SetIcon(icon, on)`、字段闪烁支持。
5. `Task_TM1729` 替换为 `Task_LCD`（50ms 周期），按当前状态机字段刷新；"----" 隔断线常显。

### P3 — 输入系统

1. EC11 正交解码逻辑保留（`transition` 表），仅引脚/极性适配。
2. 新增开始/停止键 3 次稳定消抖（低有效），产生短按事件。
3. 旋钮按键事件语义改为：单击 = 进入设置/切换字段（SPEED → TIME → 循环），替换当前长按启停逻辑。
4. 长按旋钮不再切换启停（需求未定义长按，保留悬空处理）。

### P4 — ADS1115 驱动 + 温度/测速

1. 实现 ADS1115 I2C 驱动：地址 0x48、连续转换、MUX 在 AIN0/AIN1 间轮询、FSR ±4.096V、DR=860SPS。
2. 温度换算：分压反推 PT1000 阻值 `R = 1k·V/(5V−V)`（PT1000 ∥ R18）→ Callendar-Van Dusen 公式或 0~300°C 查表。
3. PT1000 开路检测：断路时 AIN0 恒为 2.5V（分压比 1/2），插入时 ≤ 约 2.1V → 阈值约 2.3V 判开路；开路 → 温度数字熄灭 + 十字架图标灭。
4. 实时转速：ADC 采 AIN1 电平判沿计数（光耦脉冲），结合每转脉冲数换算 RPM。**注意**：860SPS 采样率上限决定测速带宽（2000 RPM、1 脉冲/转 ≈ 33Hz 可行；多脉冲/高转速需评估）。
5. 到达目标转速判定：|实际 RPM − 目标| < 阈值且持续 N 个周期，作为倒计时启动条件。

### P5 — 状态机与业务逻辑重构

1. 状态机：`APP_STANDBY / APP_SETTING / APP_RUNNING / APP_PAUSED`。
2. 设置流程：单击旋钮 → SETTING（SPEED 闪烁）→ 单击 → TIME（H-M-S 闪烁）→ 单击循环回 SPEED；5s 无操作自动确认；任意时刻按开始键立即生效并启动。
3. 运行逻辑：按新 LUT 输出 PWM；图标逻辑（时钟/圆/▲/十字架）；到达目标转速后开始倒计时（每秒递减）。
4. 暂停逻辑：停止键 → 电机停、倒计时冻结、圆/时钟图标灭、实时转速显示递减到 0。
5. 运行中设置：按旋钮进入设置，SPEED 变化实时作用于 PWM；退出后实时速度、倒计时显示刷新。
6. 上电：恢复 Flash 参数 → STANDBY，显示目标转速/时间 + 实时温度，实时转速 0、倒计时 0。
7. 倒计时归零行为：需求未定义，暂按"停止电机、保留参数"实现（列入待确认）。

### P6 — Flash 持久化扩展

- 末页 256B 重排为 32 个 8B 槽：`{magic u16, speed u16, hours u16, minutes u8, seconds u8}`，保持"末槽有效 + 写满整页擦除"的磨损均衡策略。
- 旧板槽格式（4B 转速）无需兼容（新板全新存储）。

### P7 — UART 命令与调试

- 引脚迁移后保留现有命令集；`status` 扩展输出实际转速、温度、ADC 原始值、倒计时。
- 新增调试命令（可选）：`temp`（读温度）、`adc`（读两路 ADC）、`lcd`（全段测试）。

### P8 — 验证与标定

1. Keil 编译（ARMCLANG V6.19）。
2. 逐项上板验证：5V 电源、SWD 烧录、UART、PWM 波形与电机转向、HT1623 全段点亮、按键/编码器、ADS1115 读数。
3. 电机标定：实测 100~2000 RPM 对应的占空比曲线，回填 `RpmDutyLUT`。
4. 完整业务流回归：上电 → 设置 → 启动 → 到达目标 → 倒计时 → 暂停 → 恢复 → 二次上电恢复参数。

## 4. 关键风险

1. **IOMUX 遗留调用**：若保留 `GPIO_IOMUX_ChangePin(IOMUX_PIN11, IOMUX_PB5_SEL_PD2)`，pin11 会从 SWCLK 变为 PD2，烧录口失效且与 LCD RD（pin19=PD2）冲突。**必须删除**。
2. **按键极性不统一**：旋钮高有效（下拉）、开始/停止低有效（上拉），代码中极易写反，建议集中定义极性宏。
3. **TM1729→HT1623 协议完全不同**：旧显示驱动代码不可复用，需整体重写并新建段位映射表；段位表依赖规格书第 3 页，须逐行核对。
4. **测速带宽受限**：ADS1115 860SPS 上限 + 光耦脉冲频率决定测速精度，2000 RPM 以上或低脉冲数时可能不满足"实时"要求，需实测评估。
5. **5V 电平**：全板 5V 信号，芯片允许，但注意勿在 IO 上接 3.3V 逻辑器件。
6. **Flash 槽格式变更**：新格式与旧板数据不兼容（新板无历史数据，可接受）。
