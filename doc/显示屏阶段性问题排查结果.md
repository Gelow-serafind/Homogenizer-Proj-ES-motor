## 一、屏完全不亮（已解决）

初版驱动按经验实现，有三处协议性错误：

1. **命令码错误**：误用 HT1621 记忆值（`BIAS13=0x15`、`XTAL32K=0x20`）。实测 HT1623 命令表：
   - **无 BIAS 命令**（固定 1/4 偏压、1/8 占空比）
   - 外接晶振 = `0x1C`；内部 RC 32K = `0x18`
   - 发送格式：`CS↓ + ID(100) + 9 位命令码(末位 X=0) + CS↑`
2. **RAM 组织错误**：HT1623 RAM 为 **96×4 位**（7 位地址 A6~A0，每地址 4 位数据），非"48 字节×8 位"。映射：`addr = SEG×2 + COM组(0/1)`，`位 = COM%4`
3. **位序错误**：每 nibble **D0 先发**（`...A6A0 D0D1D2D3`）

修正后屏可点亮。

## 二、只有 COM1 行亮（已解决）

现象：所有命令（`d1`/`seg0`/`raw`/`scan`）只有玻璃 COM1 行的段位（如 1a/2a/S1）显示，其余全灭；且写入内容可变化（串行口由 WR 驱动，独立于系统时钟）。

根因：初始化发送 `XTAL32K` 命令将 HT1623 时钟源切到**外接晶振 U46，而 U46 未起振** → 芯片无系统时钟 → LCD COM 扫描多路复用冻结在 COM0 相位 → 仅该相位（玻璃 COM1 行）可显示。

修复：改发 `RC32K`（内部 RC 振荡器，上电默认值），扫描恢复。

**遗留**：U46 晶振虚焊/失效未修。量产前应补焊/更换并切回 `XTAL32K`（帧频精确 64Hz）；当前用内部 RC（帧频 48~80Hz 离散）可继续开发。

## 三、暗态半亮残影（未解决）

现象：段位关闭后不完全熄灭，呈半亮；切换内容时旧段位渐暗（LCD 电荷释放，正常），但**持续半亮**为偏压问题。

分析：HT1623 为固定 1/4 偏压，VLCD 决定对比度。板上分压 `VCC5V → R5(0Ω) → VLCD → R182(10k) → GND`，VLCD=5V 满压偏高 → 暗态鉴别不足（鬼影）。原理图注释"调节对比度"，R5 即调参件。

**待办**：R5 由 0Ω 改为电阻（建议 22k~47k，VLCD≈3.4~4.1V），目标：暗态全灭、亮态清晰。可用电位器先找平衡点再固化为固定电阻。

## 四、`lcd all` 个别段位不亮（待确认）

现象（内部 RC 修复后，`lcd all` 全亮测试）：
1. Set Speed 第 2 个 8：右侧两条竖线不亮
2. Set Time 的 H 组第 2 个 8：右侧两条竖线不亮
3. 中间"----"隔断行第 1 条横线不亮

初步按段位表映射：疑似集中在 **SEG3（玻璃脚 12）** 上的 2B/2C（COM2/COM4）与 6B/6C（COM5/COM7）——但同 SEG3 的 2G/6G（COM3/COM6）疑似正常，模式不干净，**尚不能定性**。

**两种可能**：
- A. 对比度伪影（见三）——偏压临界导致部分该亮段位未达阈值，调好 VLCD 后可能消失
- B. U6 排线/驱动芯片某几根引线虚焊（U46 晶振同为虚焊，怀疑排线存在系统性焊接问题）

**待办（顺序）**：
1. 先调 R5 修正对比度 → 重跑 `lcd all` 复测
2. 仍不亮则用 `lcd d2` / `lcd seg3` 精确核对，确认死段坐标
3. 确认后检查 HT1623 芯片（LQFP100，重点 COM/SEG 相关引脚）与 U6 FPC 排线焊点，补焊复查
